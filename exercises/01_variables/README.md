# Variables

In TypeScript, you declare variables with `let` (reassignable) or `const`
(not reassignable). Unlike plain JavaScript, every variable has a type —
either inferred from its value or written explicitly as an annotation.

- [Type annotations](https://www.typescriptlang.org/docs/handbook/2/everyday-types.html#type-annotations-on-variables)
